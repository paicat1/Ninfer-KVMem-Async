## 结论（三条）
1. **"第二个 CUDA 上下文单独作用"被排除** —— 1 MiB 同样建立了上下文，两拍都健康（与"机器上本就有 ~10 个 CUDA 上下文进程而基线健康"一致）。
2. **E-E 的"100–150 MiB 边界"不可按需复现** —— 同一压力（150 MiB、同池、同请求形态）在 E-E 致谷、在本轮健康 ⇒ **该边界不是确定性的**。
3. **阳性对照失败 ⇒ 本现象的"单变量可控性"不成立** —— 唯一与该轮差异同向变化的可观测量是**请求期自由显存**（本轮稳在 328–336；E-E 掉到 167–344），但它本身也不是干净判据（E-E L=100 掉到 179 MiB 仍健康）。
