## 二、机制定位：**时间全部花在"host 侧提交"，即驱动内部阻塞**

**源码语义已核**（`src\models\qwen3_5\program\decode.cpp:172-175`）：
```
submit = host 侧提交耗时   wait = 设备等待   rest = 未归属
```

**证据（两处独立）**：

| 来源 | 样本 | 读数 |

**旁证三处吻合**：深谷的 `throughput … host 64.8 %` ✓ · 外部微基准不受影响（被阻塞的是**引擎**的提交）✓ · `layer-ops` 首层不动/后层 mixer 膨胀（被处理的是后层的页）✓

## 四、定标：触发阈值与饱和行为

| 外部新增显存需求 | 结果 |
|---|---|
| 200 MiB | **0/9 慢**（完全无效） |
| **400–600 MiB** | **每次恰好 1 个深慢探**（decode 8–9） |
| 1200 MiB | 同上（**饱和**） |
| **1200 MiB 持续 4–5 分钟** | **全程 100% 慢（decode 1.5–7.9）** |

⇒ **阈值 ≈300–500 MiB、与引擎余量无关**；**"持续施加 ⇒ 持续深谷"**（30 秒只够触发一次转换）。
