## 0. 要回答的问题（用户原话转译）

"异步页流水是不是没有发挥提速作用、和没有流水打平了？"——**在超池工况下**（工作集 > 池，搬运真实发生），把流水拆掉（同步回退）跑同一负载，看差多少。此前数字（74.4K 超池 decode 114.4 tok/s）是**带流水**的读数，"另一侧"从未测过——本实验补这一刀。

## 1. 单变量设计

| 项 | ARM-OFF | ARM-ON |
|---|---|---|
| `NINFER_ASYNC_DEMOTE` | **0**（同步批回退） | **1**（默认；显式设 1） |
| 引擎件/池/图/精度 | 同一 exe；pool 65536；graph 64；rk2v4-e8；mtp K4；vision overlay | 同左（**唯一差异 = 上行开关**） |
| 附加 | `-Depth 2`、`NINFER_DEMOTE_PROFILE=1`（engine_ctl 恒定）、reqlog 开 | 同左 |
| 引擎寿命 | 每臂**新起**（消除"长跑引擎"混淆） | 同左 |
| 负载 | `a2gate.py --filler-kb 300 --runs 3 --rounds 1 --max-tokens 600`（≈74.5K tokens > 池 65536，确定性字表 filler，确定性采样 T0） | 完全同参 |

顺序：**OFF → ON**（ON 臂结束后原样留作标准平台，免第三次重启；单轮顺序偏置无法完全消除，如实记录在案）。

## 2. 预登记判据（先写死，后看数）

- **主判据**：臂内 3 发超池请求的 `timings.predicted_per_second`（decode）**中位数之比** r = OFF ÷ ON：
  - r < 0.70 ⇒ **异步流水在超池工况净收益成立**（拆掉明显塌）；
  - 0.70 ≤ r ≤ 0.85 ⇒ **弱证据**（方向对、幅度一般）；
  - r > 0.85 ⇒ **两臂接近**（与用户"打平"怀疑方向一致）——净收益在本工况**未证实**。
- **次判据**（解释性，不参与主判）：TTFT / total / prompt 速度、错误数、`prompt exceeds` 计数、`demote profile`/`[ring]`/`STALL` 计数（= 搬运活动证据）。
- **有效性门**（不满足 ⇒ 标"无效，重排"，不解释差异）：每臂须 ①`READY` ②≥1 次 `prompt exceeds`（真超池）③≥1 条 `req# done` ④两臂都出现搬运活动迹象。
