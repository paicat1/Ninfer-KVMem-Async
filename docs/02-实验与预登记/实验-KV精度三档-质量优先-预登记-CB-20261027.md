## 〇、规范协议：无 warm

- **每档一律冷启直发，禁止 45KB warm**（跨夜可比 + 生产语义 + 已证 warm 是不对称扰动）。
- **warm 效应降级为观察项**。
- **新平台冷启基线**：**ON 320.4 / OFF 243.4（异步 +31.7%）**，与旧平台 +32% 一致。
- 慢态判据 `r1<230` 沿用（无 warm 口径）。

## 二、质量门（只跑 ON 臂）

> 质量门只挂 ON 臂（生产形态）；OFF 差异由 C-ctrl 速度对照覆盖。8 组逐字 + 埋针 3 针 × 3 深度 × 3 档全挂 ON。

1. **逐字门**（`scripts/verbatim_gate.py`）：8 组覆盖 DSH 真实域，temp0/top_p1/top_k1；记一致数 + 差异条目 + 首差位置。
2. **长生成循环**（`scripts/classify_repeat.py` max8，判据 >100）。
3. **召回埋针**（`scripts/probe_recall.py` / `probe_recall3.py`）：三层判据 ① 针被答出 ② `kept` 覆盖针位 ③ `scored_kept > 0`；**判活题面 ≤ 池**、**超池观测量面 > 池**（分列）；**每档 ≥3 针、不同深度位置**。⚠ G15 编号已撤回。

**静默截断三分辨**：`stop` / 正常触顶（`prompt+max ≤ 池`）/ 超池截断（`prompt+max > 池`，必剔除）；`finish_reason` 入档分列。**质量裁判用独立短输出请求（`max_tokens=64`）**，**速度臂保持 2000 口径**。

**诚实局限**：`NINFER_HOST_PAGEABLE=1` 下 `kept` 层平凡通过 ⇒ **有效层只有 ①+③，kept 不得当金标准**；探针只证"打分生效 + 针可检索"，不证"池压下淘汰式取舍的正确性"。

**accept 口径（#40）**：`docs/01-构建与发布/遥测口径对齐-#153-20261020.md`——分子 `draft_n_accepted` / 分母 `draft_n`，同报 `completion_tokens` / `finish_reason`。跨口径（63% vs 93.3%）不作判据。

## 三、速度臂：冷启 ABBA + run2 收集 + sha 判据（v5.1 修正）

- 每档：`NINFER_ASYNC_DEMOTE` 1/0，**冷启→单轮 ABBA**，每臂 ≥3 次复测（每次冷启或至少冷启第一发），ABBA 交错；极差比 ≤1.15、0 错误。
- 负载：a2gate `--filler-kb 300 --max-tokens 2000 --rounds 2`。**run2 必须收集**。
- **sha 判据（分档，不得跨档套用）**：
  - **A 档**：冷启第一发 r1 sha 应逐字复现 **ON `35bbafa0` / OFF `81749d21`**（跨重启复现，三重实锤）；**不一致即停**。
  - **B/C 档**：**cycle1 定锚 → cycle2 复现该锚**（同档同臂跨 cycle 逐字一致）。判据是**档内跨 cycle 复现，不是跨档复现**——换 dtype/池后文本必然不同，**禁止拿 A 档锚点套 B/C**（否则第一跑即误触发）。

## 三b、跨档 vs 档内口径（v5.1 新增，必须写清）

- **跨档速度数字（B/C vs A 的 320.4/243.4）仅列参考**——那是"**精度 + 容量**"混合效应，**不可当作异步收益判读**。
- **档内 ON/OFF 差才是该档的异步收益判读**；**精度伤的干净拆分靠 C-ctrl**（同池换 dtype）。
- **B 档判读主战场 = r2**：池 75,776 ≥ r1 的 75K ⇒ **r1 段几乎零超池、零 demote，ON/OFF 差 ≈0 是设计使然（池盖住了，异步无事可做），不是异步失效**；r2（152K > 76K）才是 demote 猛烈段。
- **C 档 r1 即超池**（58,368 vs 75K）⇒ **全程是战场**。

## 四、口径修正

1. demote 用 batch 完成行 + `demoted=` 页数总和，禁用总行数。
2. restore 需 PG2 插桩；S13 无 P-g ⇒ 只报 demote copy。
3. `max-tokens 2000` = token 上限；`len` = 字符数。
4. 相位统计用 `running N (PHASE M)` 字段。
5. **禁止 warm**；**冷启第一发才是确定性可比点**（run2 因 cache 态漂移而不同，属观察项非缺陷）。

## 五、观察项

- 异步"搬得更少"（ON `demoted` 页数少 ~40%）。
- **多轮工况（重点）**：run2 的 ON vs OFF（A 补轮样本 ON 349.3 / OFF 148.1）；若实锤则多轮下异步差值扩至 **2.4×**——最接近生产 DSH 形态。
- **#53 收敛**：跨硬件逐字全同 ⇒ 根因收敛为"逻辑页管理决策差异"。
- 机制假设：retire 快 → free 累积 → `target_free` 小 → demote 少；**C 档高字节下看是否反转**。
- "趋平"已撤销（warm artifact）；新基线 = 冷启 +31.7%。

## 六、成本与边界

- 机时：A 冷启复跑 ~10 min + B ~30 + C ~30 + C-ctrl ~15 ≈ **~1h30m**。
- 边界：单机 16GB；PPL 未在位；旧平台已消失。
- **不做**：不改引擎源码；不引入新 binary；不构造工况证明 async。
