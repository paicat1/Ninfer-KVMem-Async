## 0. 一页结论（条件化）

### 0.1 结论

**本方案给出"解决路径"，不是"解决承诺"。**

- **缓解**：第一嫌疑（PDL 依赖自旋）有启动级开关，关闭代价经两个独立来源测得 ≈0（我方 ≤1.2%【夜报告 §9】、上游 −1.1%【调研 L99】），输出逐字不变；
- **可判定的只有"出局"**：窗口内复现且 PDL 已关 ⇒ C1 出局（打点同时指名）；
- **窗口内不再现 ⇒ 只交付"未复现（窗口未证实开启）"**，不得读作 C1 成立；
- **窗口不来 ⇒ 不产根因结论**（本方案上限）。

## 4. 第 1 步：引擎件（v2 内容全恢复）

### 4.1 PDL 关闭 = 启动参数，不是代码改动

```
env  NINFER_PDL_OFF=1        # S7 启动语义
```
- **捕获期生效**（`pdl.cuh` L109 的 `pdl_kill_switch()` 启动时定）⇒ 必须重启起服；
- **部署核验（不可省）**：起服后必须看到引擎自报 `[ninfer] PDL: programmatic … DISABLED`（防"以为关了没关"）；
- S10 标志文件只影响**新捕获的形状**，对已捕获图无效 ⇒ 不用它做判决；
- 回退 = 去 env。

### 4.2 新增打点（唯一需要写代码的部分）

| 打点 | 位置 | 说明 |
|---|---|---|
| **物化段** | `context_kv_materialize` 调用前后（`ops\context_kv_materialize\materialize.cu`，`enter_streaming():411` / `enter():459`） | 自家 §12.2 的 ⭐⭐⭐ 一号等待点；缺它则"自旋在物化链上"时指不到 |
| **forward 内 op 组** | `run_layers(Phase::Verify)` 内（`text.cpp` 族） | 按**实际代码**划分（预期方向：embed / GDN gating / GDN recurrent / sliding-window attn / MoE-GEMM / lm_head；以读码为准） |
| **draft 内** | `execution\draft.cpp` / speculative round | **先读实现再定分段数与段名**（不预设） |

**取舍**：`candidate_selector`（接受路径）暂不单独打点——S9 实测 accept≈0.01 ms；槽够才附带。

**硬前置（施工首步锚）**：读 `step_graph_profile.h` 核**槽位预算**（**按 10 槽已满办**）与打点 API 签名；读 `run_layers` 与 draft 路径按实际代码列分组。

**机制出处（v4 新增）**：本打点机制**已存在**——`step_graph_profile.h` L3/L19 明写**门槛 = `NINFER_STEP_PROFILE`（默认关、零行为）**，S6 的 `%globaltimer` 段戳即走此门；本方案是**扩槽**，不是新造机制。

### 4.3 仪器门（打印门 + 判据 + 基线 + Σ）

- **打印门（头文件 L23 原文全文）**：**"慢轮（总跨度>100ms）或前 3 轮/VERBOSE 时打印一行"** ⇒ ① **30–100 ms 的慢轮不打印**；② **前 3 轮恒打印**；③ **VERBOSE 每轮打印**（这正是本方案"有界 VERBOSE 健康基线"的**现成实现依据**）；
- **多通道判据明细（恢复）**：探针 **decode<60**（45KB/60-tok 形状的健康带 101–119）· **fresh `verify` ≥30 ms** · **打点行数新鲜度**（`verify` 只在每 64 轮窗口打一次，须比行数防陈旧）；
- **健康基线**：有界 VERBOSE 采样（同形状、同缓存态、固定节奏 N 轮，预登记）；
- **Σ 会计规则**：**Σ(各 op 组) ≈ verify 总量（±10%）**；对不上 ⇒ 存在"未归属区"，不得读作"各 op 组均匀"。

### 4.4 观察者效应自检（协议量化）

| 项 | 值 |
|---|---|
| 设计 | **交错 A/B**（A=step11，B=新件），**n ≥ 7 轮/臂** |
| 控制 | 同形状（45KB/200-tok）、**同缓存态**（每轮前同 prompt 预热）、同起服参数 |
| 主判据 | **`verify` 毫秒（中位数）**；次判据 decode；辅证 sha 逐字一致 |
| 弃用规则 | 两臂主判据差 **>2%** 或 sha 不同 ⇒ **仪器作废**，退回"只关 PDL"最小方案 |

### 4.5 构建与部署

```
build\s6_1208a.bat（--parallel 6） → archive_build.ps1 归档 → engine_ctl start/waitready（§9.1）
```
- **成本**：op 组打点需扩槽（10 槽已满）⇒ **全量重编 20–40 min**（历史口径：10-11 记录"全量重编 25–40 分钟可接受"）；
- **零行为门**（S2/S3b 门规，进部署链）：新件须过"**开/关两臂 sha 逐字相同 + decode 零变化**"；**仪器层自带此门**（`NINFER_STEP_PROFILE` 默认关、零行为，头文件 L3/L19）；
- 起服后核验自报 `DISABLED`（§4.1）。

## 5. 第 2 步：授权时段待命（无固定时长）

### 5.1 授权模型

- **不设任何固定时长**；机器开不开、开多久 = **您的决定**；引擎默认**不开**；
- 仪器就绪后**待命**：有授权时段内，谷一出现当场读档。

### 5.2 观测力条款（**v4 重写：窗口是主门，流量只决定观测机会数**）

| 项 | 规定 |
|---|---|
| **主门（更正）** | 谷的出现**主因是"机器态窗口"**，不是负载：反例实锤——**S12 深负载连续 8.5 h（12 窗 / ~1500 负载轮 / ~170 探针）零谷**，而 00:47–02:13 同样深负载 85 分钟出 5 次。⇒ **流量只决定"每日观测机会数"，窗口决定"有没有现象可观测"** |
| 观测源（二选一，您定） | **(a) 您的自然用量**；(b) **最小自检探针：每 5–10 分钟一发 60-token 探针**（**示意值，由您定**），量级**远低于** S12 负载，**不属"加压抓谷"** |
| 记账分离 | **"无流量时段"与"无谷"必须分开记**；无流量时段**不计入阴性样本** |
| 观测力参照 | 窗内带负载 85 min 抓 5 次 vs 纯空转 4.5 h 抓 0 次——**但此对照的混淆是窗口与负载同变**，只能作"探针节奏"参照，**不得作"负载诱因"证据** |

### 5.3 判据（先验，恢复行内明细）

| 观察 | 结论 |
|---|---|
| 窗口内出现慢轮（**probe decode<60 或 fresh verify≥30 ms**）且 **PDL 已关** | **C1 出局**；同时读打点指名 |
| 慢轮且打点可读，单一 op 组（含物化段）**>60%** 且 Σ 规则通过 | 指名归因 |
| 各 op 组均匀（Σ 规则通过） | 自旋在调度/等待层 ⇒ 读 13 个等待点 |
| **未复现** | **只交付"未复现（窗口未证实开启）"**——不得读作 C1 成立或已根治 |
| OFF 期出现慢轮 | 必须做**同一性声明**（与 ON 夜指纹并列比对：spin-stamp 段形 / target-draft 比 / verify 分布） |

### 5.4 终止（无时间预算）

① 抓到 1 个慢轮并读出 op 组 = 成功收工；② **您说停 = 立即停**；③ 机器关闭即结束（不要求为实验开机）。
