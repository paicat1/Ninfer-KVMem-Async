## 0. 一句话

**把"抓谷"从限时实验窗升级为"常驻 + 案件驱动"：让真实生产运行当诱饵，谷露头的那一分钟秒级冻结现场、抓齐证据包；证据成立后自动起草"复现验证申请"，再上一级申请"工程级验证"。**

定位：**兜底通道**——当所有工程级诱发试验（自诱导审计、受控自然窗、按需触发对照）都关不上"自然触发源是谁"这个问题时启用。不替代当前主方案，只补它的空。

## 1. 背景（为什么值得做）

1. **谷的习性已明确**：只栖息在长跑引擎（新起臂从不出现）。而换臂/重启式实验天然把这一条件掐掉——S12（8h/12 窗）、今晨 observe_A v1（180 分钟/118 探针）零谷，都是"在谷的栖息地之外打猎"。
2. **已确立**：外部显存压力 ⇒ 引擎 host 提交阻塞 ⇒ 谷，**可按需复现、释放即恢复**（主方案 v2 §0）。"人造谷"有了；**未解的是"自然谷的触发源是谁"**（以及"我们自己的工具是不是那些窗口的制造者"——自诱导混淆，审计中）。
3. **常驻是唯一能把"引擎连续运行时长"这个最强相关变量拉满到天/周量级**的形态；其活动时间线天然就是自诱导审计所需的"我方活动线"数据源。
4. **成本低、与现有实验正交**：影子模式可并行，不占实验窗（只要不重启引擎）。
5. **缺取证包的捕获 ≈ 又看了一次"谷来了"；有取证包的捕获 = 可差分归因的案卷**——这是本系统存在的全部意义。

## 2. 设计三原则

| 原则 | 落点 |
|---|---|
| **智能** | 多信号触发（防误报）→ 秒级捕猎；案件驱动 → 自动分析、起草申请；模板预制 → 案发时只填空（现场没有写报告的时间） |
| **系统** | 全部挂在现有守望者谱系（observe_A / valley_supervisor / window_watch / a2gate）上做**增量升级**；与"心跳＋回执＋待办"协作机制对接；不另起炉灶 |
| **科学** | 预登记判据（先写死再看）；对照样本（前后基线）；证据可追溯；每个假设配可判别实验 |

## 3. 三级响应阶梯（核心设计）

### 一级 · 当场捕猎（全自动，不申请——现场易腐）

- **触发判据**：多信号 ＋ 连续确认（见 §5）。
- **动作（秒级，冻结优先）**：
  1. **冻结现场**：写保护锁——案发期间禁止任何重启/改配置/构建靠近引擎；
  2. **快照四件套**（见 §4）落盘 `案件目录 case_<时间戳>\`；
  3. **防抖去重**：一段谷（按主方案 v2 的 verify 分层口径）记一案，附起止时间戳；
  4. **通知**：案件索引落盘（供 CB/TELE 值守心跳发现——案发即"落件"）。
- 为什么全自动：谷只活几分钟，逐案申请来不及。

### 二级 · 现场扰动取证（预授权一次、长期有效；有界；零破坏）

- **前提**：用户**一次性批准**的"现场微取证预算"（数值见 §10 待决策）。
- **边界写死：只加"测"，不加"压"**——零配置变更、零重启、**零压力注入**。
  - 理由：当前主方案正在审计"压力类工具与谷的因果"（自诱导混淆）——二级绝不能自己污染这一点。压力类试验一律属三级申请。
- **内容**：
  1. 探针频率短时提升（测衰减曲线/持久性：谷是衰减还是骤停？）；
  2. 读引擎内部计数器与捕获状态位（`captures.aborted/completed/skipped`）；
  3. 机器采样短时加密（阈值触发，有上限）；
  4. 记录"是否释放即恢复"（对照已知人造谷的恢复行为）。
- **铁序：先冻结、后扰动**。顺序反了 = 毁尸（重启/清缓存/改档都可能瞬间抹掉现场）。
- **产出**：案件包 v1（快照 + 扰动观测数据 + 时间线）。

### 三级 · 升级申请（"申请" ≠ 自批；逐级）

1. **复现验证申请**：证据成立（n≥2-3 件全套案卷、指纹一致）→ 猎人**自动起草**申请单：案件包 ＋ **预登记**复现实验设计（判据先写死）＋ 资源/窗口预算 ＋ 风险声明 → 交用户/TELE 裁决。
2. **工程级验证申请**：复现立住 → 申请补丁构建/对照臂/长窗（遵守既有纪律：如构建只排窗间隙、不占实验窗）。
- 语义：**"申请" = 把材料备齐等人批**。猎人越智能，越要警惕"自批"——本设计从根上不给它自批的口子。

## 4. 案发取证包（成败核心——字段清单）

| # | 字段 | 目的 |
|---|---|---|
| 1 | **现场快照（±2 分钟）**：主机高频采样（CPU/内存/缺页/页文件/句柄）、`nvidia-smi -q`（**时钟/功耗/throttle reasons**）、显存 | 物理面第一手嫌疑 |
| 2 | **引擎内脏**：四层仪器逐层读数（"每层 3.3ms vs 健康 0.19ms"均摊指纹）、KV 池统计、reqlog 捕获状态位 | 软件路径证据 |
| 3 | **对照样本**：案发**前后各一份**同格式正常基线 | 差分归因的前提；缺对照，单张快照价值减半 |
| 4 | **环境指纹**：引擎连续运行时长、驱动版本、PDL 状态、二进制+参数"配方哈希" | 区分"我方锅/环境锅"；跨案可比 |
| 5 | **自活动时间线**（关键新增）：案发 ±30 分钟内一切我方工具/构建/重启事件 | 直接服务"自诱导混淆"审计——案件的第一个问题：**案发时我们自己在干什么？** |

## 5. 触发判据（防误报——宁慢十秒，不冤枉一次）

- 主判据：探针 **decode < 60**；
- 辅证（防单点噪声）：**verify 抬升**（按主方案 v2 既有分层口径：轻 30–100 / 谷 100–226 / 深 226–500 / 极深 ≥500 ms）＋ **四层仪器均摊指纹**出现 ＋ **连续 2 拍确认**；
- 全部判据**预登记**（先写死、后观察；判据变更须记录并标注生效时刻）;
- 误报代价 = 骗走一整夜实验窗 + 污染审计数据——**宁慢十秒，不冤枉一次**。

## 7. 护栏（四条，全部机器化）

1. **守望者的守望者**：心跳 ＋ 外部自检 ＋ **静默死亡告警**（先例：S13 计数停摆、陈旧值问题拖了 12+ 小时才被处理——常驻件"静默死"比"死"更危险，会让"零捕获"变成假象）。
2. **低扰动**：探针 ≤1 发/分钟（observe_A 节奏）；**绝不为多抓而加负载**——观察者把猎物吓跑是这类工作最经典的自杀。
3. **磁盘/日志帽**：沿用 logCap 500MB / reqlog 128MB×2 轮转；常驻拉长到天级后重核总量预算；案件包按容量帽滚动归档。
4. **毕业/止损线（必须写死，防养玄学）**：
   - **升格**：n≥2-3 全套案卷且指纹一致 → 升"假设检验轨道"；
   - **止损**：连续 X 天零捕获、或 N 次捕获后仍零可判别差异维度 → 转"**检测 + 有界自愈**"轨道（把未解之谜降级为"带指纹、可检测、可恢复"的已知风险）；
   - **没有止损线的蹲守 = 玄学孵化器**。

## 8. 与当前主方案/当前窗口的关系（防互相污染）

- 当前 12h 窗口（08:00–20:00，19:30 硬收尾）内：主方案三步（修仪表 → 自诱导审计 → 受控自然窗）是主战场；**猎人暂不启用**（避免新变量入场）。
- 由审计结果决定猎人角色（二选一分流）：
  - 审计指"**自诱导**"：猎人降级为"**纯守望记录**"（只记录不扰动，持续维护自活动时间线）；
  - 审计指"**机器侧自然源**"：猎人升格为**常驻捕猎主通道**。
- 猎人预制的判据/模板/快照器可反哺主方案第 3 步 A/B 组作**现成件**——两边不重复造。

## 9. 明确不做的事

- ❌ 案发期间重启引擎（重启 = 毁尸）；
- ❌ 自批申请（"申请"语义 = 批准后执行）；
- ❌ 在用户不在场且未授权时进入执行（**当前整份文件就是讨论稿**）；
- ❌ 为多抓而加负载/加压力（压力类一律走三级申请）。
