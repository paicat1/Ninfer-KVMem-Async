# 引擎构建物版本台账（2026-10-26 立）

## 为什么要这份台账

**构建物（exe，1.3 GB 级）不进 git**：`.gitignore` 有 `engine/`（L8）与 `*.dll`（L94）两条规则，且 GitHub 单文件硬限 100 MB，1.27–1.31 GB 的引擎件 push 必拒。

**但不进库 ≠ 不能定版本。** 版本由四样钉死：**源码基 + 补丁集指纹 + 构建配方 + 产物 sha256**。二进制放魔搭，这份台账进 git——别人照配方重编，sha256 对得上就是同一版本；对不上说明源码/补丁/参数有一处不同。

版本命名：**`<件系>-<发布日>-<arch>`**（本例 `sym3-20261026-sm120a`）。

### 配方（四样）

1. **源码基**：本仓自持工作副本 `engine-src/`（分支 `line-coder390`，根含 `PROVENANCE.md`；**未入库**，对外复现走本仓 `engine-main` 分支或 `repro/*.bundle` + `patches/`）
2. **补丁集**：`patches/*.patch` 共 **20 个**；**集指纹**（各补丁 sha256 按名排序后拼接再取 sha256）= `E7F05AC5ECAA1FF78A3C9C8B0233FFB7FDBC93DD9C85971C7F26A29DEB3AC982`
3. **构建配方**：`build/s6_1208a.bat`，**必须显式传** `-DCMAKE_CUDA_ARCHITECTURES=120a -DNINFER_SM120_NATIVE=ON`（CMake 默认落 sm_86 ⇒ 启动挂死）；带符号件另注入 `/Zi` + `LINK=/DEBUG`
4. **产物验收**：`cuobjdump --list-elf` 核 arch（见上）

### 运行依赖（不随包，用户自取）

16 个 DLL 必须与 exe 同目录，缺一即 `0xC0000135`：CUDA 13.3 提供 `cudart64_13/cublas64_13/cublasLt64_13`；vcpkg 提供 ffmpeg（`avcodec/avformat/avutil/swresample/swscale`）与 `libcurl/z`。
**不随包的原因**：ffmpeg 组件为 **LGPL-2.1**，随包分发需附源码或书面索取途径；由用户自装可绕开该义务。CUDA runtime 依 NVIDIA EULA 允许再分发，此处不随包仅为省事。
