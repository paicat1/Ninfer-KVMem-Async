## 二、明确失效的区域（不得作为事实来源）

以下目录里的内容**一律视为历史遗迹**，可以读来理解"以前怎么做的"，但**不能据此判断"现在该怎么做"**：

| 目录 | 为什么 |
|---|---|
| `_quarantine\` | 隔离区：因违规/绕过门禁被移出的脚本（`do_publish.ps1` 就在这里） |
| `_safety_backups\` | 删前副本，仅用于回滚 |
| `archive\` | 已归档的日志/文档 |
| `retired\` | 退役区 |
| 任何 `*.bak_*` | 二进制/脚本的改前备份 |
| 项目根以外的路径（`J:\` 下其他目录） | 不属本仓，不受本仓治理约束，也可能是别的项目 |

## 三、"我记忆里有 X" 时的强制动作

只要结论来自记忆而非本轮读到的文件，**必须做一次验证再开口**：

| 记忆内容 | 必查 |
|---|---|
| "某个 worktree 在 XXX" | `git worktree list` + `WORKTREE_LEDGER.txt` |
| "某个脚本负责 YYY" | `Get-ChildItem -Recurse -Filter <名字>`，并确认**不在** `_quarantine` / `_safety_backups` |
| "某个池上限是 N" | `ninfer_launcher.py` 的 `MODEL_KVCAP_MAX_*`（当前值）+ 构建史对应节 |
| "某条规则允许 ZZZ" | `.codebuddy\rules\项目硬规则.mdc` + `scripts\gates.ps1` 对应门 |
