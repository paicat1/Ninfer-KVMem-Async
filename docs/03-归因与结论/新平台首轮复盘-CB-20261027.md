## 一、平台变量（§176，构建史 L4131）

本次唯一受控变量 = 换主板 + 换 CPU（新 CPU 带核显）：

| 项 | 旧平台 | 新平台 |
|---|---|---|
| PCIe | 已 BIOS 降 **Gen4**（WHEA 止血） | **原生 Gen5**（带宽 ×2） |
| 独显空闲 VRAM | 886 / 949 MiB（独显扛桌面） | **242 MiB**（桌面改核显） |

⇒ 仅 PCIe 代数、CPU、桌面归属三项变，**GPU 本体不变**（后文 #53 推论要靠这条）。

## 二、六件大事

### 2.1 warm artifact 勘误（§176 补记⑥，L4207–L4215）——本轮最重

45 KB warm 是 300 KB filler 的**前缀**，灌进 prefix cache，**且对 OFF 不对称**（236 → 327.6）。

- **撤销**：~~"新平台 ON≈OFF 趋同、异步优势消失"~~、~~"OFF r1 +38.8%（327.6 vs 236.1）硬件红利"~~
- **修正**：两臂均匀 +2.5~3%；同步臂冷启几乎没提速（243 vs 236）
- **真实新平台冷启基线**：**ON 320.4 / OFF 243.4 = 异步 +31.7%**，与旧平台 **+32% 完全一致**
- ⇒ **异步优势 = 调度结构固有收益，跨平台稳定**（不是硬件红利）
- 规范协议从此定为**无 warm**（L4216）

**方法论污染模式（必须记）**：warm 不是中性操作——当 warm 文本是主负载的前缀时，它改变的是**命中率不对称性**，而非"两边都预热"。这类协议污染不报错、不异常，只悄悄篡改基线。

### 2.2 #53 根因收敛到"纯逻辑"（L4217 + lummy 增量 1）

**事实链**：四臂 sha **跨硬件逐字全同**（A 补轮无 warm 版与 §167 全同）⇒ 文本由（配置 + 负载）唯一决定。

**候选 A 升格（lummy 补的更强推论）**：

1. GPU 本体未换（换的是主板/CPU/桌面归属）；
2. Gen5 带宽 ×2 也没有改变 sha ⇒ **页搬运时序不影响数值**；
3. ⇒ 分叉纯粹由**逻辑决策序列**决定（哪些页被选去 demote、按什么顺序 restore）；
4. ⇒ **候选 A（attention gather 按逻辑页序遍历）从"候选"升为自洽的唯一机制层**——求和序由页序决定，页序由逻辑决策决定，硬件只执行、不改变页序。

**结论**：#53 的机制空间从"硬件玄学 + 逻辑算法"收敛为**纯逻辑算法**。G2 读码从此不必再考虑任何硬件变量（变量大幅减少），与 PG2 运行时插桩互补且**零机时**。

### 2.3 #56 自己推翻了一半（§176 补记②④，L4162–L4197）

- 旧"点火 1058 vs 663"= `demote profile` **retire 行污染**的假象；按 batch 行 + `demoted=` 页数（成本承载完成事件）：异步一直**比同步搬得少**（旧 3.2×、新 5×）
- demote 成本 **97–99% 在 prefill 段**，decode 段仅 1.2–8.3 ms（2–5%）⇒ **"不装节奏器"保住**（翻案所需的 decode 高占比实测不成立）
- 干净成立的一项：demote copy 旧 ~1.6–2.0 ms → 新 ~1.1 ms（**1.5–1.8×**，与 Gen5 带宽 ~2× 吻合）
- **边界**：这是 demote 侧；restore 侧仍按 §173 待同口径重跑

**工程上更对的解法已落地**：patch 23（`patches/23_restore_batch_publish.patch`）把每步 **740 次 publish / ~7.4 ms host 时间**改成收集后一次批量 publish（L40–42）⇒ **不装节奏器，但 host 开销直接砍**。

### 2.4 KV 精度三档质量门（§177，L4220–L4237）

**决定性结论**：**输出文本只由 KV 数值精度决定，与池大小 / 超池深度无关**——池 65,536 → 58,368（超池更深）**一字不改**（8/8）。

| 对比 | 变量 | content 一致 |
|---|---|---|
| A(rk2v4@65,536) vs C-ctrl(rk2v4@58,368) | **同 dtype，池缩 11%** | **8/8** |
| C(rk8v4@58,368) vs C-ctrl | 同池换 dtype | 3/8 |
| A vs C / A vs B | dtype+池 | 3/8 |
| B vs C | 两个"更高精度"互比 | 4/8 |

- 差异**只在开放式生成**（代码风格 / 措辞）；p3/p4 JSON、p5 逐字复述**三档全同** ⇒ 确定性任务不受 KV 精度影响
- B 档第 3 cycle：r1 **≈0**（+0.5%）、r2 **+21%**，r1 sha 三轮全同 ⇒ n=3 达成
- **判读边界（硬）**：逐字门是**借用第三方 ≥7/8 判据**（设计用于同模型不同配置）；跨精度差异**只记录、不判过/拒**；`ninfer-perplexity` **不在位** ⇒ 无质量裁判；`verbatim_gate` 逐请求关思考 ⇒ **未覆盖思考通道**（生产为 high + 16k）

## 四、慢态（#58）的新处境

### 4.1 事实

- **新平台本次未跑出慢态**（§176 补记①，L4153）
- C-ctrl 归因里 **STALL=0 ⇒ 慢态出局**（§177 遗留，L4237）
- 慢态 v3 的仪器（1 Hz 采样 + 事后 join + clocks.mem）**仍未被验证，也未被否证**——没发作就没有采样机会
- 旁证同构：C-ctrl ON `demoted 5390 ≪ OFF 9653`（走"已 host 副本快速路径"，**慢在 ring/verdict 等待**）⇒ "慢在等待而非搬运"的又一形态

### 4.2 核显化机制候选（lummy 增量 4，新增，可验证）

**机制候选**：旧平台桌面渲染（DWM / 合成器）挤在独显上 ⇒ WDDM 队列 + 显存占用 + DPC 压力；新平台**核显扛桌面** ⇒ 独显外部干扰源骤降。

- 与既有线索同构：CB 候选② DPC 延迟（打断 host 提交路径）、C-ctrl"慢在等待"、自旋指纹（GPU 烧周期等提交）
- **可验证实验（比"等发作"和"预冷"都便宜）**：BIOS 强制**独显输出**，跑一次同负载——
  - 慢态复现 ⇒ 触发源 = 桌面输出负载 ⇒ **核显化就是根治**，慢态正式降级为"旧平台桌面争用现象"
  - 慢态不复现 ⇒ 核显化不是主因，回到自旋/clocks.mem 线
- **注意**：这是候选，不是结论；必须在**同一新平台**上改 BIOS 输出做 A/B，不能跨平台比

## 六、风险与空白

1. **编译非确定性**（L4127）：同 source 同配方 3 个 size。**零机时捷径**（lummy 增量 3）：3 个 binary 跑同负载对照——输出 sha 全同 ⇒ "同 binary"约束可降级为"同 source + sha 台账"，风险即时消解；不必先做编译器考古。
2. **新平台 Gen5 + 外压 400 未复测**（L4267 / L4154）：卡死形态、谷三条件都只在旧平台验过。对外只能写"第一层通过"。
3. **深档 2× 未在新平台复验**：+32% 是冷启 r1；depth 3/4 深载未跑。
4. **run2 cache 态漂移**（L4218）：A 补轮 run2 **ON 349.3(+9%) vs OFF 148.1(−39%)**——同会话第二发同步臂崩、异步臂反升。生产 DSH 多轮**第二发才是常态**，若实锤则多轮异步差扩至 **2.4×**。**当前最值钱的未定项**。
5. **质量方向无裁判**：PPL 工具不在位；思考通道未覆盖（§2.4）。
