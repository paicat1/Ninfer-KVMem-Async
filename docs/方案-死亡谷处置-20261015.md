## 5. 第 2 步（**重写**：撤 48 h，改"授权时段待命 + 机会主义捕获"）

### 5.1 授权模型（机器开关 = 您）

- **不设任何固定时长**。机器开不开、开多久 = **您的决定**；
- 引擎是否常驻 = 您一句话（默认：**不开**）；
- 仪器就绪后**待命**：在有授权的时段，谷一出现当场读档；**没有"等 N 小时"这一项**。

### 5.2 观测力条款（TELE 二审第 ② 条）

**没有轮次就没有观测**——"零负载守望"在无流量时段会退化成"零观测"，并被误记成"无谷"。因此：

| 项 | 规定 |
|---|---|
| 观测源（二选一，您定） | **(a) 您的自然用量**（最真实，但可能整夜空转）；**(b) 最小自检探针**：每 **5–10 分钟**一发 60-token 探针，量级远低于 S12 负载，**不属"加压抓谷"** |
| 记账分离 | **"无流量时段"与"无谷"必须分开记**：无流量的时段不计入阴性样本 |
| 历史观测力参照 | 窗内**带负载** 85 分钟抓 5 次；**纯空转** 4.5 h 抓 0 次 ⇒ 两者观测力差一个档（这是 S12 的教训） |

### 5.3 判据（先验，同 v2）

| 观察 | 结论 |
|---|---|
| 窗口内出现慢轮且 **PDL 已关** | **C1 出局**；打点同时指名 |
| 慢轮且打点可读，单一 op 组（含物化段）>60% 且 Σ 规则通过 | 指名归因 |
| 各 op 组均匀（Σ 规则通过） | 自旋在调度/等待层 ⇒ 读 13 个等待点 |
| **未复现** | **只交付"未复现（窗口未证实开启）"**——不得读作 C1 成立或已根治 |
| OFF 期出现慢轮 | 必须做**同一性声明**（与 ON 夜指纹并列比对） |

### 5.4 终止（写死，无时间预算）

① 抓到 1 个慢轮并读出 op 组 = 成功收工；② **您说停 = 立即停**；③ 机器关闭即结束（不要求为实验开机）。
