# 规范：文件五操作（新建 / 修改 / 备份 / 转移 / 清理）

- 作者：桌面版 CodeBuddy（CB）· 2026-10-17 · 起因：用户质问"新建、修改、备份、转移、清理，都想清楚了吗"
- **定位**：本件是《设计-文件与目录治理》的**操作层**；规则数据在 `structure.json`；门禁 `scripts/gates.ps1`。
- **三问（每次动手前必答）**：① 这是什么阶段？② 属于哪个家？③ 引用都改了吗？

---

## 0. 总则

1. **规则即数据**：白名单/禁则/命名/git 边界/配额/活件三源 全在 `structure.json`，检查器读数据。
2. **路径不硬编码**：脚本/文档引用**逻辑名**，物理位置只在注册表（`engine_registry.json`）出现。
3. **钩子只检查、不移动**；一切移动/删除 = **清单 + 批准 + 门禁**。
4. **数字必带"截至时刻"**（本仓曾因不标时刻产生 108/114 类口径分歧）。

## 1. 新建（Create）

| 项 | 规则 |
|---|---|
| **准入制** | 类别不在规范 ⇒ **先改 `structure.json` 再建目录**（不许随手建） |
| **默认家** | 默认落 `work/<YYYYMMDD>/`；**只有明确属于某家**才直接写那里（如工具产出直接写 `evidence/`） |
| **命名** | 见 §6；`scripts/` 禁"过程名"（`fix3.py` `_selftest2.py` `add_final.py` …）——那些是一次性脚本，属 `work/` |
| **脚本转正** | 一次性脚本**不转正**；被文档/报告引用后 ⇒ 移入 `scripts/` 并改名为 `<动词>_<对象>` |
| **新建后** | 跑 `gates.ps1`（引用 + 结构） |

## 2. 修改（Modify）

| 对象 | 规则 |
|---|---|
| `evidence/`（案卷等） | **只增不改**；需更正 ⇒ **追加更正件**，不覆盖原案卷 |
| `docs/history/`（构建史） | **只追加**；每节带日期 + 作者 |
| **多写者文件**（协作状态/请审件） | **分区 + 只追加**：每方一个节，**不得覆盖他人节**；追加前**重读尾部** |
| `refs/ engine-src/ official-repo/` | **只读**（不改不删） |
| 现行脚本/配置 | 可改；**改前扫引用**（`check_refs.py`）、**改后跑门禁**（`gates.ps1`） |
| **编码/换行** | 含中文 `.ps1` **必须带 BOM**；机器可读 JSON **必须无 BOM**；**保持原 CRLF/LF**（整文件换行变更 = 禁止，除显式声明） |
| **编辑方式** | **定点替换优先**；整文件重写须显式理由（曾因重写改变行序/换行，diff 膨胀且丢过内容） |
| **改"活件"**（引擎/配置） | 先查**活件三源**（运行进程映像 / 登记册 / 最近写入 <300 s） |

## 3. 备份（Backup）

**三律**：
1. **入库文件不另存副本**（git 即备份）；
2. **未入库文件删除前必备份**到 `_safety_backups/<date>/` 并**记 sha**；
3. **同 sha 只留一份**（用 `hash_cache.json` 判重）——这是 6.36 GB 重复 exe 的根治。

| 类型 | 位置 | 保留 |
|---|---|---|
| 删前备份 | `_safety_backups/<date>/` | **30 天** |
| 活件版本 | `engine/lineage/` + 注册表登记（含 sha） | 永久（谱系） |
| 配置 | **git** | 永久（历史） |
| **永不删** | `evidence/` `retired/` `refs/` `engine/lineage/` | — |

## 4. 转移（Move/Transfer）

| 步 | 内容 |
|---|---|
| ① **清单** | 源→目标 · 条数 · 体量 · **引用清单**（谁引用它） |
| ② **活件判定** | 三源命中 ⇒ **先改写入方（工具）路径 + 安全窗口**（TELE 最严重条：8 类"正在被写入"的件） |
| ③ **执行** | **移动（非复制）**；注册表/规则数据同步改（**只改一处**） |
| ④ **验证** | `gates.ps1`（引用 + 结构） |
| ⑤ **登记** | 转正写指针（报告/索引）；退役写 `retired/INDEX.md` |
| **禁止** | 跨家复制；同名不同家（除 `active`/`lineage` 版本关系）；**历史文档里的文字记载不改**（只追加） |

## 5. 清理（Cleanup）

| 来源 | 时机 | 规则 |
|---|---|---|
| `work/` 过期 | **7 天（自动）** | 定时任务；**自动清也留日志** |
| `_safety_backups/` 过期 | **30 天** | 同上 |
| 重复副本 | 确证同 sha **且活件三源未命中** | 先清单（含 sha）→ 批准 → 执行 |
| `logs/` | 滚动 **14 天** | 保留当前 + 最近 |
| **永不清理** | `evidence/` `retired/` `refs/` `engine/lineage/` · git 管的东西 | — |
| **删除四步** | 每次删除 | ① 记 sha + 扫引用 ② 改**全部**引用 ③ 验**可解析** ④ **断链先恢复**（同 sha/hash_cache/回收站/_trash），改引用是次优 |
| **回收站** | — | 删除走回收站（可恢复）；**清空 = 真删 ⇒ 必须显式批准** |

## 6. 命名规范（此前完全缺失）

| 对象 | 规则 |
|---|---|
| 文档 | `<类别>-<主题>-<作者>-<YYYYMMDD>.md`（类别 ∈ 方案/审核/报告/设计/规范/FAQ/夜研/归因） |
| 脚本 | `<动词>_<对象>.py|.ps1`（如 `check_refs.py`、`gates.ps1`） |
| **禁入 `scripts/`** | `fix*` `_selftest*` `add_*` `patch_*` `append_*` `tmp_*` ⇒ 属 `work/`（**已由检查器强制**） |
| 证据 | 工具生成名（`case_<时间戳>` 等）**不得手改** |
| 退役 | 保留原名 + `INDEX.md` 登记 |
| `work/` | 自由命名（反正 7 天清） |

## 7. git 边界（哪些进、哪些必须忽略）

- **必须忽略**（已由检查器校验 `.gitignore` 覆盖）：`work/ _trash/ _safety_backups/ logs/ models/ engine/ engine-src/ official-repo/ refs/ .temp/ __pycache__/ *.pyc`
- **必须入库**：`docs/ scripts/ patches/ build/ structure.json engine_registry.json README* 启动器.bat ninfer_launcher.py`

## 8. 体量红线（超线进每周审计告警）

| 家 | 告警线 | 处置 |
|---|---|---|
| `logs/` | 500 MiB | 滚动 14 天 |
| `_safety_backups/` | 8 GiB | 30 天清 |
| `work/` | 2 GiB | 7 天清 |
| `engine/` | — | **同 sha 只留一份** |

## 9. 审计指标（每周 7 项 → `evidence/audits/<date>.txt`）

① 根白名单外条目数（应 0）② `work/` 最老条目年龄（≤7 天）③ `_safety_backups` 体量与最老件（≤30 天）④ **同 sha 重复件数（应 0）** ⑤ 未登记退役件（应 0）⑥ 断链数（基线只降不升）⑦ 证据区是否含临时物（应 0）

## 10. 灾难恢复（四源）

| 丢什么 | 恢复源 |
|---|---|
| 二进制 | `hash_cache.json`（sha 查重）+ `engine/lineage/`（同 sha 副本）+ **回收站** |
| 代码/文档/配置 | **git**（含历史） |
| 证据 | `evidence/`（只增）+ `logs/` 原始日志 |
| 近删 | `_safety_backups/`（30 天） |

## 11. 一次性文件的判定与处置

- **判定三中**：① 只为一次性任务而生 ② 无功能性引用 ③ 不含唯一数据
- **处置**：留 `work/`，**7 天自动清**；**一旦被报告/文档引用 ⇒ 转正**（改名 + 移入 `scripts/`）
- **反例对照**：`fix_gate2.py`（一次性 → work/）vs `check_refs.py`（工具 → scripts/）
