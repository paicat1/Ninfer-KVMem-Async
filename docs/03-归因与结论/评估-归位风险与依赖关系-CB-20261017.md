# 评估：归位风险与依赖关系（回答"搞完以后是不是绝对安全"）

- 作者：桌面版 CodeBuddy（CB）· 2026-10-17 · 实测：`git ls-files` 359 跟踪件 · 可扫描文本 327 件

## 一、先直答：**不是"绝对安全"。我不给这个承诺。**

**能给的是三件**：① **可验证**（门禁 `gates.ps1` 跑引用 + 结构）② **可回滚**（一批一提交；未跟踪件走回收站 + 备份）③ **分批推进**（零影响批先做）。
**不能给的**：把"绝对"写进承诺——因为**有些引用类型机器抓不到**（见 §四），且**仓外引用我扫不全**。

## 四、残余风险（诚实列出——这就是"绝对"不可能的原因）

| # | 风险 | 为什么机器抓不到 | 缓解 |
|---|---|---|---|
| 1 | **运行时拼接路径** | 如 `os.path.join(ROOT,'docs',name)`、`'tools\' + x` | 改为**注册表逻辑名**（P2/P3 顺手做）；抽查关键脚本 |
| 2 | **散文按名引用** | "见 `docs/方案-…md`" 不是路径 | **`docs/INDEX.md` 映射表**（旧→新） |
| 3 | **隐含约定** | 工具期望某文件名/目录（如 `logs/test_valleywatch.log`） | 移动**目录**而非改**文件名**；工具路径同批改 |
| 4 | **仓外引用** | `schtasks` 计划任务 · 桌面快捷方式 · TELE/CLI 记忆 · 你书签 | **执行前通知**（队列置顶）+ 索引留映射；**无法扫全 ⇒ 必须留回滚** |
| 5 | **活件** | 正在写入/在跑 | **活件三源判定**（命中即跳过）+ 安全窗口 |
| 6 | **我自己的判断错误** | 本轮已抓到 1 例（4B json 是活配置） | **依赖量化前置**（本轮即是）+ 清单里标"是否跟踪/是否被引用" |

## 六、验收标准（每批）

1. `gates.ps1` **rc = 0**（引用 + 结构）
2. `git diff --stat` **只见 rename / 删除**，无整文件重写
3. 受影响文件清单**逐条核对**（本轮方法：扫 token 取"功能引用"）
4. **一批一提交** + 提交信息写"批号/件数/引用改动"
5. 退役件登记 `retired/INDEX.md`
