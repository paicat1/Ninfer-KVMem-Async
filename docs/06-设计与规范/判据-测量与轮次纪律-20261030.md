# 判据：测量纪律与池策略分界（2026-10-30）

> **来源**：`挂账总表-20261030.md` 的 P3-1（判据）、C1（池策略分界）、P3-2（轮次）。
> **性质**：把散在 10-20 ~ 10-28 五份文档里的测量要求，收成一页可直接照做的判据。
> **纪律**：本页只写"怎么测、怎么判"，不复述结论。

## 一、轮次与有效性（先满足这个，其他判据才有意义）

| 项 | 要求 | 出处 |
|---|---|---|
| **每臂轮次** | 同臂**连续 ≥3 轮**；单轮数据**没有资格作结论** | 速度实验批预登记 / 总纲核查 |
| **每轮必录** | **WHEA 条数 / `clocks.sm` / 功耗 / 温度 / 换页计数** | 总纲 Q1 |
| **有效性门** | 每轮 `pow ≥ 120 W` 且 `clk ≥ 2500 MHz` 且无 429；否则该轮作废重跑 | 显存余量预登记 §三 |
| **离散度判据** | **轮间极差比 ≤ 1.15**（弃 CV 说法：n=3 时 CV 功效不足） | 总纲核查 §三 |
| **基线选择** | 用**当日最早的健康窗**作分母，不用"当晚基线"（慢态晚基线本身是慢的） | 慢态 v3 §5.3 |
| **慢态判据** | **相对降速 > 20%（对当日 healthy 窗）且 `decode < 90`**；旧 `decode<60` 已作废（漏检 123.8） | 慢态 v3 §5.3 |

## 二、跨臂与跨档的口径（最容易错的地方）

| 场景 | 能不能比 | 说明 |
|---|---|---|
| **跨臂（ON vs OFF）同配置同轮** | ✅ 可判 | 这是异步收益的唯一合法读法 |
| **跨档（dtype/池不同）绝对值** | ⚠ 只列参考 | 是"精度 + 容量"混合效应，**不可当异步收益** |
| **跨日/跨环境** | ❌ 不可比 | 除非有当日共同基线；"2 倍速度"就是这么错的 |
| **sha 跨臂** | ❌ 不该相同 | 调度类开关**不承诺**逐字一致；同臂跨重启才是确定性判据 |
| **sha 跨档** | ❌ 不该相同 | 换 dtype/池后文本必然不同；只承诺**档内跨 cycle 复现** |

## 三、环境前提（决定"能不能测出差异"）

> **2026-10-18 BIOS Gen5→Gen4 降档**（WHEA 止血）后，**Gen4 下换页密集类操作耗时 ×2**
> ⇒ **任何 < 2 倍的优化在当前环境不可测**。

**推论**：patch 23 类"host 侧簿记优化"在当前环境测得 TTFT −0.71%，**属"测不出"，不是"无效"**。

## 四、池策略分界（C1 的答案）

两套口径都成立，但**适用域不同，必须分开写**：

| 口径 | 适用域 | 判据 | 出处 |
|---|---|---|---|
| **A · 对外保守** | 交付给使用者 | **池 ≥ 预期最大 prompt**；超池属"研究级"，对外不做承诺 | 快速上手 L53 |
| **B · 研究级小池** | 我们自己做实验 | 设备池可小到 **4,032 token（63 页）**；此时**必须**核 `kvmem_score: SELECT` 行数 | KVMem 教程 §2/§3 |

**B 的成立条件（缺一不可）**：

1. 主机池 ≥ 逻辑上下文所需（k8v4 ≈ **25 KiB / token**，256K ≈ 6.6 GiB）；
2. `[ring] content scoring ON by default` 出现；
3. 发过请求后 **`kvmem_score: SELECT` 行数 > 0**；
4. 读引擎 over-pool 告警（`prompt > pool`）—— **它出现就说明该请求的答案不许当已核**。

**文档写法要求**：对外材料只写 A；研究记录写 B 时必须同时写上面四条，**不得只写"小池也行"**。
