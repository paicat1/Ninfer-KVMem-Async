## 四、排查序列（区分主板 vs 显卡的路径，从零成本到动硬件）

技术定性：Receiver Error = 物理层信号错误。报错点在根端口（主板侧），但信号链路涉及：显卡发送电路 → 金手指接触 → 插槽 → 主板 PCB → CPU 根端口——**软件层面无法区分哪一端**，需交叉测试逐层定位：

1. **重插显卡**（断电操作；清洁金手指/插槽）→ 观察：好了=接触问题；好一阵又犯=接触面劣化
2. **BIOS 降 PCIe Gen5 → Gen4** → 观察：不报了=信号裕量问题（常见缓解路径；性能损失约 1–2%）
3. 若 ①② 无效：**显卡换槽**（如有第二 x16 槽）→ 报错跟卡走=**显卡侧**；不跟=**主板/插槽侧**
4. 终极区分：换卡 / 换主板 / 送修
5. 并行检查：12V-2x6/12VHPWR 供电接头插紧、线材无折损

**进度：②已执行**（2026-10-18 18:11 BIOS 降 Gen4 + 重启，hostmax=4 生效；重启后暂未复现 WHEA——待 GPU 负载验证）；若负载下复发 ⇒ 做 ①（重插）或 ③（换槽）。
