# 挂账总表（2026-10-30 · v2 按时效性组织）

> **v1 的错误**：按"文档写完的日期"排序，等于把 10-09 的说法当成今天的待办。
> **v2 的规则**：**每条必须写「提出日 → 失效日 + 失效依据」。没有失效日的才能进待办。**
>
> **判据**：失效依据必须是**当前代码/配置/更晚文档的明确推翻**，不能是"我觉得过时了"。
> **一句话**：**文档日期 ≠ 事项有效期。** 引用旧文档 = 讲历史，不是讲现状。
