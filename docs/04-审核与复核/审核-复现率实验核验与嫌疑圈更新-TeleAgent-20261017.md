## 二、新发现（TELE 判读）

1. **深谷粘性（重要）**：全部谷拍释放后**显著残留**（0.19–1.10 s；健康 0.027 s）——"状态"不随压力移除而消失（对比：浅谷历史上"释放即恢复"）⇒ **"粘性"= "状态"驻留在"引擎不可自清层"的直接证据** ⇒ 支持"机理层在驱动/系统侧"的方向；
2. **谷后连续谷（观察）**：shot 5 谷后，shot 6–8 连续谷/停滞（各拍"起始值"= 上拍残留：188,899 → 1,104,331 → 815,264）——**"谷后状态"跨拍延续**；但 shot 6–8 均为 400 档（**"谷后效应" vs "400 效应"未分离**——留后续设计）；
3. **暴露史排除**：shot 5 首发谷于"4×HEALTHY 干净历史" ⇒ **暴露史非必要前提**；
4. **free 第 N 次证伪**：shot 5（谷）请求期 free **337–383** 高于 shot 1–4（健康）**300–334**；
5. **持有构成恒定**：10 个 CUDA 进程全实验不变（shot 1–4 健康期间亦然）⇒ 进程数量非因子（再次确认）；
6. **400 档内部也不确定**：shot 6/7 完全停滞 vs shot 8 出 token（0.99 s/round）——同剂量不同形态 ⇒ 概率性再证。

## 三、嫌疑圈更新（当前盘点）

**已排除（10 项）**：设备等待 / 引擎搬页 / OOM / CPU / 主机内存 / 准入 / 第二 CUDA 上下文 / 请求形态单独 / free 数值 / 暴露史（作为必要前提）。
