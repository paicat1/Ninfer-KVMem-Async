## 二、三组实验（一次一变量，按序执行）

### A 组 · MTP draft 扫描（最便宜，先做）

- **变量**：`--spec mtp --draft-tokens N`，N = **3 / 4（基线） / 5**（launcher 现档 k1–k5）。
- **每次流程**：停服 → 改档起服 → 就绪 → a2gate 探针 ×3 取中位 → 逐字门 8 提示。
- **判据**：① **decode tok/s 最高** ② 记录接受率 `draft_n_accepted / draft_n`（**K 越大通常越低**）③ **逐字门必须 8/8 通过**。
- **甜点判据**：decode 最高 **且** 逐字门通过。
- **边界**：若 N=5 仍在上行 ⇒ **不自行扩档**，回报后另立"扩到 6–8"预登记（须先确认引擎是否支持 `--spec mtp --draft-tokens 6..8`）。

### B 组 · 异步深档 3/4（**有前科，强制监控**）

- **变量**：`NINFER_ASYNC_DEMOTE_DEPTH` = **1 / 2（基线） / 3 / 4**（launcher 现档 1–4）。
- **每次流程**：停服 → 改档起服 → **深载驱动**（ee_threshold 或 a2gate 深轮）。
- **判据**：深载 decode + ring STALL。
- **强制监控**：谷判据（decode<60 持续）+ **WHEA 必须为 0** + 活件三源（nvidia-smi 计算进程 / 登记册 / 近期写入）。
- **前科**：v2.1 曾 **depth≥2 入谷回归**（在飞页不计入空闲裁决 ⇒ 搬运自我放大），已由 `claimed_pages` 两本账修复，**但深档 3/4 从未实测**。
- **熔断**：入谷不恢复 / WHEA 复发 ⇒ **立即回滚 DEPTH=2** 并停批上报。

### C 组 · `--prefill-cublas`（带质量门）

- **变量**：开 / 关（基线=关）。1 次起服 + 质量门。
- **判据**：prefill 时间改善 **且** 逐字门 8/8；**收益 ≥5% 才收**（否则不采纳）。

## 三、通用纪律

1. **一次一变量**；跑完一组先给用户看数据，再进下一组。
2. **速度不能换质量**：任何组逐字门失败 ⇒ 该组作废、回滚基线。
3. **停服前先确认无用户/任务在用 8094**（T#0058）；实验期间不对外提供服务。
4. 每次起服后查 **WHEA（0 条）** 与活件三源。
5. 不改引擎二进制；配置改动**仅通过 launcher / 命令行参数**。

---

## 四、回滚

任一节点出现 **逐字门失败 / WHEA 复发 / 入谷不恢复** ⇒ 回滚基线（K4 / DEPTH2 / 无 cublas）+ **停批** + 上报。
