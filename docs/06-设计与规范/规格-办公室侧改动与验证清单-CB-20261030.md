### 2.1 P0-6 build.info 进构建脚本

**目标**：产物旁生成 `build.info`（源码 HEAD / 分支 / 脏标记 / 补丁集指纹 / preset / arch / cl+nvcc 版本 / exe sha256）。

**方案 A（推荐）**：独立脚本 `tools/write_build_info.ps1`，由构建脚本在 link 成功后调用。

**草案**（办公室已写但**未验证**，实验机可改）：

```powershell
# tools/write_build_info.ps1
param(
    [string]$Src = 'J:\ninfer-kvmem\engine-src\src-tree\fusion-engine-src',
    [string]$Exe = '',
    [string]$Out = '',
    [string]$PatchesDir = '',
    [string]$Presets = '',
    [switch]$Strict
)
$ErrorActionPreference = 'Continue'
$repo = Split-Path -Parent $PSScriptRoot

function Try-Exec([string]$exe, [string[]]$argv) {
    try { return ((& $exe @argv 2>&1 | Out-String).Trim()) } catch { return '' }
}
function Get-FileSha256([string]$path) {
    if (-not $path -or -not (Test-Path -LiteralPath $path)) { return '' }
    try { return (Get-FileHash -LiteralPath $path -Algorithm SHA256).Hash.ToLower() } catch { return '' }
}

if (-not $PatchesDir) { $PatchesDir = Join-Path $repo 'patches' }
if (-not $Presets) {
    $p = Join-Path $Src 'CMakePresets.json'
    if (Test-Path -LiteralPath $p) { $Presets = $p }
}

$srcHead = ''; $srcBranch = ''; $srcDirty = ''
if (Test-Path -LiteralPath (Join-Path $Src '.git')) {
    $srcHead   = Try-Exec 'git' @('-C', $Src, 'rev-parse', 'HEAD')
    $srcBranch = Try-Exec 'git' @('-C', $Src, 'rev-parse', '--abbrev-ref', 'HEAD')
    $d = Try-Exec 'git' @('-C', $Src, 'status', '--porcelain')
    $srcDirty = if ($d) { 'dirty' } else { 'clean' }
}

$patchRows = @(); $patchAggregate = ''
if (Test-Path -LiteralPath $PatchesDir) {
    foreach ($f in (Get-ChildItem -LiteralPath $PatchesDir -File -Filter *.patch | Sort-Object Name)) {
        $patchRows += [pscustomobject]@{ name = $f.Name; sha256 = (Get-FileHash -LiteralPath $f.FullName -Algorithm SHA256).Hash.ToLower(); bytes = $f.Length }
    }
    if ($patchRows.Count -gt 0) {
        $joined = ($patchRows | ForEach-Object { $_.sha256 }) -join ''
        $sha = [System.Security.Cryptography.SHA256]::Create()
        $patchAggregate = (($sha.ComputeHash([Text.Encoding]::ASCII.GetBytes($joined)) | ForEach-Object { $_.ToString('x2') }) -join '')
        $sha.Dispose()
    }
}

$presetSha = Get-FileSha256 $Presets
$cudaArch = ''; $presetName = ''
if ($Presets -and (Test-Path -LiteralPath $Presets)) {
    try {
        $j = Get-Content -LiteralPath $Presets -Raw | ConvertFrom-Json
        $presetName = $j.name
        foreach ($prop in $j.configurePresets) {
            if ($prop.cacheVariables -and $prop.cacheVariables.CMAKE_CUDA_ARCHITECTURES) { $cudaArch = [string]$prop.cacheVariables.CMAKE_CUDA_ARCHITECTURES }
        }
    } catch { }
}
$clVersion   = ((Try-Exec 'cmd' @('/c','cl 2>&1')) -split "`n" | Where-Object { $_ -match 'Version' } | Select-Object -First 1)
$nvccVersion = ((Try-Exec 'nvcc' @('--version')) -split "`n" | Where-Object { $_ -match 'release' } | Select-Object -First 1)

$exePath = ''
if ($Exe) {
    if (Test-Path -LiteralPath $Exe) { $exePath = (Resolve-Path -LiteralPath $Exe).Path }
    elseif (Test-Path -LiteralPath (Join-Path $repo $Exe)) { $exePath = (Resolve-Path -LiteralPath (Join-Path $repo $Exe)).Path }
}
$exeSha = ''; $exeBytes = 0
if ($exePath) { $exeSha = Get-FileSha256 $exePath; $exeBytes = (Get-Item -LiteralPath $exePath).Length }

$now = Get-Date
$info = [ordered]@{
    schema = 'build.info/1'; built_at_local = $now.ToString('yyyy-MM-dd HH:mm:ss zzz'); built_at_utc = $now.ToUniversalTime().ToString('yyyy-MM-ddTHH:mm:ssZ')
    host = $env:COMPUTERNAME; src_root = $Src; src_branch = $srcBranch; src_head = $srcHead; src_dirty = $srcDirty
    patch_count = $patchRows.Count; patch_set_sha256 = $patchAggregate; patches = $patchRows
    preset_name = $presetName; preset_sha256 = $presetSha; cuda_arch = $cudaArch; cl_version = $clVersion; nvcc_version = $nvccVersion
    exe_path = $exePath; exe_bytes = $exeBytes; exe_sha256 = $exeSha
}
if (-not $Out) { $Out = if ($exePath) { "$exePath.build.info" } else { Join-Path $repo '.temp\build.info' } }
$dir = Split-Path -Parent $Out
if ($dir -and -not (Test-Path -LiteralPath $dir)) { New-Item -ItemType Directory -Force -Path $dir | Out-Null }
$json = $info | ConvertTo-Json -Depth 5
[IO.File]::WriteAllText($Out, $json, (New-Object Text.UTF8Encoding $false))
[IO.File]::WriteAllText("$Out.json", $json, (New-Object Text.UTF8Encoding $false))
$lines = @('build.info -- generated by tools/write_build_info.ps1')
foreach ($k in $info.Keys) { if ($k -ne 'patches') { $lines += ("{0}: {1}" -f $k, $info[$k]) } }
$lines += 'patches:'
foreach ($p in $patchRows) { $lines += ("  {0}  {1}  {2} B" -f $p.sha256, $p.name, $p.bytes) }
[IO.File]::WriteAllText("$Out.txt", ($lines -join "`r`n") + "`r`n", (New-Object Text.UTF8Encoding $false))
Write-Output ("BUILD-INFO: {0}" -f $Out)
if ($Strict -and (-not $srcHead -or -not $exeSha)) { exit 2 }
exit 0
```

### 2.2 P2-1 机器态采样器（`scripts/machine_state_sampler.ps1`）

**目标**：1 Hz 记录机器态，**必须含 `clocks.mem`**（M1 假说的唯一判据字段）；慢态触发时 5 Hz × 30 s 自加密；零 GPU 占用、可与任何实验并行。

**草案**：

```powershell
param(
    [double]$IntervalSec = 1.0,
    [double]$FastIntervalSec = 0.2,
    [int]$FastWindowSec = 30,
    [string]$OutDir = '.temp',
    [string]$FlagFile = '.temp\slowdown.flag',
    [int]$MaxHours = 0
)
$ErrorActionPreference = 'Continue'
function Ensure-Dir([string]$p) { if ($p -and -not (Test-Path -LiteralPath $p)) { New-Item -ItemType Directory -Force -Path $p | Out-Null } }
Ensure-Dir $OutDir
$flagDir = Split-Path -Parent $FlagFile; if ($flagDir) { Ensure-Dir $flagDir }
$csvPath = Join-Path $OutDir ("machine_state_{0}.csv" -f (Get-Date -Format 'yyyyMMdd'))
$header = 'ts_local,ts_gpu,clocks_sm_mhz,clocks_mem_mhz,power_w,util_gpu_pct,util_mem_pct,temp_c,pcie_gen,pcie_width,mode'
if (-not (Test-Path -LiteralPath $csvPath)) { Set-Content -LiteralPath $csvPath -Value $header -Encoding ASCII }
$query = 'timestamp,clocks.sm,clocks.mem,power.draw,utilization.gpu,utilization.memory,temperature.gpu,pcie.link.gen.current,pcie.link.width.current'
$deadline = if ($MaxHours -gt 0) { (Get-Date).AddHours($MaxHours) } else { [datetime]::MaxValue }
$fastUntil = [datetime]::MinValue; $ticks = 0; $fastTicks = 0
while ((Get-Date) -lt $deadline) {
    $now = Get-Date; $mode = 'normal'; $raw = $null
    try { $raw = (& nvidia-smi --query-gpu=$query --format=csv,noheader,nounits 2>$null) | Select-Object -First 1 } catch { }
    if ($raw) {
        $p = @($raw -split ',' | ForEach-Object { $_.Trim() })
        $trigger = $false
        if ($FlagFile -and (Test-Path -LiteralPath $FlagFile)) { $trigger = $true; Remove-Item -LiteralPath $FlagFile -Force -ErrorAction SilentlyContinue }
        if (-not $trigger -and $p.Count -ge 4) {
            $sm = 0.0; $pw = 9999.0
            [void][double]::TryParse($p[1], [ref]$sm); [void][double]::TryParse($p[3], [ref]$pw)
            if ($sm -ge 2600 -and $pw -lt 110) { $trigger = $true }
        }
        if ($trigger) { $fastUntil = $now.AddSeconds($FastWindowSec); Add-Content -LiteralPath $csvPath -Encoding ASCII -Value ('{0},,,trigger,,,,' -f $now.ToString('yyyy-MM-dd HH:mm:ss.fff')) }
        if ($now -lt $fastUntil) { $mode = 'fast'; $fastTicks++ }
        Add-Content -LiteralPath $csvPath -Encoding ASCII -Value ((@($now.ToString('yyyy-MM-dd HH:mm:ss.fff')) + $p + @($mode)) -join ',')
        $ticks++
    }
    $sleepMs = [int](1000.0 * $(if ($mode -eq 'fast') { $FastIntervalSec } else { $IntervalSec }))
    if ($sleepMs -lt 50) { $sleepMs = 50 }
    Start-Sleep -Milliseconds $sleepMs
}
Write-Output ("SAMPLER-DONE ticks={0} fast={1} file={2}" -f $ticks, $fastTicks, $csvPath)
```

**验收清单（实验机）**：

- [ ] UTF-8 **with BOM** + `Parser::ParseFile` 无错
- [ ] 跑 60 s：CSV 行数 ≈ 60，`clocks_mem_mhz` **非空且非 N/A**
- [ ] `pcie_gen` / `pcie_width` 有值（慢态时用于排除链路掉档）
- [ ] 起引擎跑一个短负载：采样器与引擎**互不影响**（decode 与不跑采样器时同量级）
- [ ] 手工 `echo x > .temp\slowdown.flag`：下一 tick 出现 `trigger` 行 + 30 s 内 5 Hz
- [ ] 手工构造 F1 指纹（若可行）：自查触发同样生效
- [ ] 跨日滚动：`machine_state_YYYYMMDD.csv` 新文件带表头
- [ ] 磁盘：1 Hz ≈ 11 列 × 24 h ≈ 20 MB/天（可接受）

### 2.3 P2-2 `valley_watch` 判据改「相对降速」

**现状**（`scripts/valley_watch.ps1:91`）：`decode<80 = 降级`（绝对阈值）。
**问题**：慢态晚的基线本身是慢的 ⇒ 绝对阈值会被慢基线稀释（`§164 冷暖填互换` 教训的变体）。

**改动规格**：

```
判据 = (decode < 当日 healthy 窗中位 × 0.8)  且  (decode < 90)
healthy 窗 = 当日最早 10 个 probe 的中位（且 decode ≥ 120 才算 healthy）
若无 healthy 窗（整天都慢）⇒ 用历史基线 165–171（§174 N0）作分母
```

**验收清单**：

- [ ] 用历史日志回放（`.temp/valley_*` 或 `logs/test_valleywatch.log`）：慢态窗能被判出

### 3.1 P3-1 轮间极差比 ≤1.15

任何两臂对比，**同臂多轮极差比 >1.15 ⇒ 该批作废重跑**（`§167` 实测 1.001 是合格样本）。
每轮必录：WHEA 计数 / `clocks.sm` / `clocks.mem` / 温度 / 换页。

### 3.2 P3-2 单臂 ≥3 轮

单臂单轮**不得**作为结论的强证据（`§184.5` 已按此标注“每格只有 1 轮”）。方向性对比可用，但结论措辞须带“方向性”。
