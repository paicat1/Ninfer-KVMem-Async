## 二、结论（四条）

1. **"池越大 decode 越慢"是假象**（谷态漂移）：端点复测 43K=220.5/220.9、57K=220.8/220.8 ⇒ **池大小对 decode 无影响**；四臂首测的单调下滑（217.9→65.9）与 18:57–19:00 的降级窗完全重合。**方法论收益**：三明治复测再次救场（呼应 §10.3"台阶之外看不见台阶"）。
2. **池大小不影响输出**：四臂（跨不同机器态）逐字门内 8/8 全等 ⇒ 内容与池无关（与 A2 lossless gate 互证）。
3. **nvfp4 性能 = rk2v4 同档**：220.8 vs 基线 220 级（精算 §7.3 的"最快档"预期成立）；冷填 5.35 s 无差。
4. **容量行实测（比 §7.2 预测略宽松）**：43K→513.6 MiB / 49K→414.3 / 53K→261.9 / 57K→260.5 free；**四档全部起服成功**（无越线拒绝）⇒ nvfp4 在本机可到 **57,344（56K）**，超出精算"稳定 53,184"预测。
