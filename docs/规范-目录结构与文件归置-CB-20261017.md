## 三、规范（canonical structure）

```
J:\ninfer-kvmem\
├─ README.md · README.en.md · LICENSE · NOTICE.md          # 对外
├─ 启动器.bat · ninfer_launcher.py · serve_tee.py          # 现行入口（根目录，便于双击）
├─ engine_registry.json · deploy_engine.ps1 · smart_push.ps1
├─ engine/          # 二进制：lineage/(谱系·只读) · self-built-20261008/(现役) · pdb_archive/ · *.dll
├─ models/          # 权重（只读）
├─ patches/         # 源码补丁
├─ build/           # 构建脚本
├─ scripts/         # ★唯一工具目录（吸收 tools/），分子目录：launch/ watch/ probe/ pressure/ checks/ build/
├─ docs/            # ★分类：public/ plans/ reviews/ reports/ history/
├─ evidence/        # ★实验证据：cases/ ledgers/ samples/ baselines/
├─ logs/            # 引擎日志（滚动 + 保留 N 天）
├─ work/            # ★临时工作区（取代 .temp；按天分目录；不进 git；每周清）
├─ retired/         # ★退役区：launchers-2026xx/ scripts-2026xx/ engines-2026xx/（只增不删，登记）
├─ _safety_backups/ # 删前备份（仅"删前副本"；30 天后清）
├─ _trash/          # 删除暂存（规则见下；在跑引擎映像例外，已标注）
└─ refs/ engine-src/ official-repo/                        # 第三方（只读）
```

### 六条铁律

1. **一类一个家**：工具只在 `scripts/`；证据只在 `evidence/`；临时只在 `work/<YYYYMMDD>/`；退役只在 `retired/`。
2. **根目录只放现行入口**（≤ 6 个文件）；过期件**进 `retired/` 不删**，并在 `retired/INDEX.md` 登记（谁、何时、为什么退役）。
3. **证据不得留在临时区**：案卷/台账/采样一旦产生即入 `evidence/`（案卷按冻结规则只读）。
4. **删除四步**（DECISIONS #43）：删前记 sha + 扫引用 → 删时改**全部**引用 → 删后**验证可解析** → 发现断链**先恢复**（同 sha / hash_cache / 回收站 / _trash），改引用是次优。
5. **归置动作规范化**：先出**清单**（源→目标、条数、体量）→ 用户批准 → 执行 → 跑 `scripts/check_refs.py` 核引用 → 登记。
6. **门禁**：`scripts/ref_gate.ps1`（推送前检查引用完整性，断链 > 基线即拦）。
