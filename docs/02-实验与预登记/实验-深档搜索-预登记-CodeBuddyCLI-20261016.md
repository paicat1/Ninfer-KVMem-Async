## 8. 结论（不外推版）

1. **深档今晚复现成功：2/2 于"会话头两次长持"**（R1 17:32、R2 17:39；同一引擎、不重启），形态与夜研-2 唯一那次几乎同构（[1.5,1.5,26.1] vs [1.6,1.6,8.8]）→ **"深档不可复现"的旧状态被本轮部分改写：它在"引擎被长持压过之前的窗口"里是可命中的**。
2. **剂量不是主变量**：1200 与 2400 同为深档，3600 反落谷档（顺序混杂）；**决定性反证是同剂量复验失败**（R1 深 → R1rep 谷）。⇒ 主导因素更可能是**"引擎的受压历史（第几次长持）"**而非剂量/时长/脉冲。
3. **时长（600 s）与脉冲串（6×）都不产深档**（R4/R5 全谷档）。
4. **8.5 分钟静置不恢复深档**（R7 谷档），且引擎常驻显存静置期间**不自动回涨**（15,499 恒定）——"等一会再来"不是复现配方（至少 8.5 min 级不是）。
5. 综合假说（待下轮检验）：**深档 ↔ 引擎"高压常驻态"的首次释放**——头一两次长持把引擎推入特定迁移状态（常驻 15,750→15,5xx 的"瘦身"），该状态被"用掉"后后续压力只产生 ~12 档的稳定谷；恢复条件未知（>8.5 min 静置无效）。**下轮候选**：① 什么条件能让引擎重新长满（时间/负载类型？）后再测；② ~~引擎重启后的首持（未测格，最便宜的下一枪）~~ **（已测：见 §10——深档 2/2 命中）**；③ 重建 KV 状态（如跑一轮重载）后首持。
6. **诚实边界**：命中 2 / 未中 6；顺序设计；可能存在窗口性（今晚 17:32–17:44 的"深档窗口"与夜研那次单发同型，与"机器态窗口"三层画像呼应）。不外推为"任何时刻都可复现深档"。
