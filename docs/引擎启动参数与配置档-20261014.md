> 立档 2026-10-14（用户令）。**用途**：① 把 `serve_tee` 启动命令行里每个参数的"是什么/为什么这个值"讲清；② 维护两套配置档——**Coder390（定稿）** 与 **SWIFT-1.5（现行·待测更新）**。

| 名字 | 例子 | 作用 |

## 1. 参数全表（按功能分组）

### 1.1 程序与权重（位置参数）
| 参数 | 现行值 | 说明 |
|---|---|---|
| `<exe>` | `engine\test-run\ninfer-serve.exe` | 引擎程序。`test-run` 是**换装目录**：每次起服从 `engine\lineage\` 归档件拷贝进来，保证跑的是受控档 |
| `<model>` | `models\swift15_iq3s_mtp.ninfer` | **权重真身**（位置参数，不带 flag） |

### 1.2 网络与标识
| 参数 | 现行值 | 说明 |
|---|---|---|
| `--host` | `127.0.0.1` | 只本机监听（不暴露外网） |
| `--port` | `8094` | 服务端口（全部工具/客户端指它） |
| `--model-id` | 自动（见 §0） | 服务招牌名 = API `model` 字段 |

### 1.3 上下文与 KV 池
| 参数 | 现行值 | 说明 |
|---|---|---|
| `--max-context` | `262144` | **逻辑上下文上限 256K**（模型原生） |
| `--kv-capacity` | `65536` | **设备 KV 池 64K tokens**。池外的页由 KVMem 环下沉 host（"池 < 上下文"是设计，但**需要 `NINFER_KV_WINDOW` 才允许启动**） |
| `--host-kv-mib` | `16384` | 主机侧 KV 池 16 GiB（下沉/换出的落地处） |
| `--cuda-graph-allowance-mib` | `192` | 给 CUDA 图**预留**的预算；**SWIFT 件实测须 ≥192**（64 时告警 `CUDA graphs used 236.8 MiB but the KV sizing allowed 64.0 MiB`，账面少算 ~173 MiB，贴边时易莫名拒启） |
| `--prefill-chunk` | `512` | 预填分块（比官方 1024 省 workspace，起服余量更大） |

### 1.4 KV 精度
| 值 | 每 token 字节 | 备注（本机实测取向） |
|---|---:|---|
| `rk2v4-e8` | 13.0 KiB | 最省；**Coder390 定稿** |
| `nvfp4` | 18.4 KiB | "免费档"：速度≈现状、内容距离同级 |
| `rk8v4` | 26.1 KiB | **速度最快 + 接受率最高**（SWIFT 档首选） |
| `int8` | 33.8 KiB | 近无损参考（-0.002% PPL）；池最小 |

### 1.5 投机解码
| 参数 | 现行值 | 说明 |
|---|---|---|
| `--spec` | `mtp` | 用 **MTP 头**做投机。⚠️**谷（自旋）就在这条路上**：不传 `--spec` = 裸解码（谷消失，decode 上限 ≈56） |
| `--draft-tokens` | `4` | 每轮草稿 4 token（K=4）——"tok/轮"几何来源 |

### 1.6 视觉
| 参数 | 现行值 | 说明 |
|---|---|---|
| `--vision` | 开 | 启用视觉通路 |
| `--vision-residency` | `overlay` | 视觉塔驻 **pinned 主机内存**、仍走 GPU 算（折中档，不占设备视觉显存） |

### 1.7 仪器（观测，逐档开关）
| 参数 | 现行值 | 说明 |
|---|---|---|
| `--request-log-jsonl` + `--request-log-max-mib 128` + `--request-log-keep 2` | 守望者档开 | Stage0 逐请求结构化日志（128 MiB 滚动、留 2 份） |

### 1.8 服务默认与采样（客户端可逐请求覆盖）
| 参数 | 现行值 | 说明 |
|---|---|---|
| `--default-max-tokens` | `32768` | 服务端默认输出上限 |
| `--default-reasoning-effort` | `high` | 默认思考强度（本线 EfficientThink 必开） |
| `--default-thinking-budget` | `16000` | 默认思考预算（防"思考墙"烧光输出→空正文） |
| `--max-concurrency` | `1` | 单并发——**KVMem 环硬约束**（>1 环无法回收设备页，启动即拒） |
| `--max-shared-prefixes` | `0` | 关跨会话前缀共享（隔离/确定性） |
| `--presence-penalty` / `--temperature` / `--top-p` / `--top-k` | `0` / `0.7` / `0.9` / `20` | 官方采样档（测试工具在请求里覆盖为 argmax：`temp=0 / top_p=1 / top_k=1`） |

### 1.9 止血
| 参数 | 现行值 | 说明 |
|---|---|---|
| `--recover-invariant-failures` | 开 | 不变式失败只废当前请求、不弄死引擎（定稿）；**不要**用旧 `--kv-lease-growth`（深超池会静默截断输出） |

## 5. 变更纪律（每档生效）

1. **招牌名不写死**：`engine_ctl` 按件自动切 + 工具从 `/v1/models` 读（§0）；
2. **换档走启动器 `MODEL_BUNDLES`**（q2lynn / swift / bonsai 一键切 KV·池·Graph·视觉）；
3. **一次一变量**；跨档对比必须**池 ≥ 上下文**（否则测到的是检索子集效应）；
4. **golden SHA 只在同模型同档内可比**；换档先立新基准（`baselines\<档>\`）；
5. 起服窗口/长任务遵守窗口 SOP（可见 + 标题 + 干完清窗）。
