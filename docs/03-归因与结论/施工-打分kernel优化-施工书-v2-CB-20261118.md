## 二、刀 1a/1b 具体改动（含行号）

**刀 1a**：`kvmem_retrieve_launch.cu:78-103` 点积内核
- 现状：逐元素标量循环，单累加器
- 改为：`float4` 载入（head_dim 256 = 64×float4）+ 4 个独立累加器 + 尾部归约
- **不动**：累加结果参与 `atomicAdd` 的语义与次数（每 (b,layer,token) 1 次，:219-221）

**刀 1b**：同文件
- phase1/phase2 结构（`179`/`239` 附近）改为：`for h in 0..heads-1 { 计算全部 (block) 的 dot → 写 s_logits[h]（16KB）→ 并行 max → 每 head 质量累加进本线程寄存器 local[⌈4096/256⌉]，24 head 全部完成后**每 b 恰一次 atomicAdd**（保持 :219-221 语义，禁止 per-head atomic） }`
- launch 参数：`shmem = n_blocks * sizeof(float)`（4096→16KB）；**仅当 >48KB** 才调 `cudaFuncSetAttribute`（正常路径不触发）
- **不动**：`head_w` 的 `1/(L*H)`（:271-277）、mask 早退（:262-266）、early-return
- **放弃 v1 的 `s_logits[n_blocks]` 全头缓存**（B1 阻断项）
