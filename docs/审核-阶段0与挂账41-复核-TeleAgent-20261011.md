## 三、挂账41 复核（394e70e）— 机理源码证实 + 观测存疑

### 3.1 SseTransport 心跳/取消机制健全 — **证实**

[EVIDENCE] `http_transport.cpp:200-224`：
```cpp
bool SseTransport::mark_cancelled() noexcept { cancelled_.store(true,...); return true; }
void SseTransport::write(...) { if (cancelled_.load(...) || !sink_.write(...)) { mark_cancelled(); throw ClientDisconnected(); } ... }
bool SseTransport::poll(...) { if (cancelled_...) return true; if (sink_.is_writable && !sink_.is_writable()) return mark_cancelled(); ... }
```
→ write 失败→取消+抛、poll 查 is_writable、心跳间隔发送——**机制健全证实**。CB 主张"socket/心跳层无病灶"成立。

### 3.2 取消检查点位置 — **证实**

[EVIDENCE] `openai_chat_http.cpp:200`：

→ 取消检查点确实挂在**输出回调**（decode 步间），与 CB 主张一致：若 decode 步冻结在更深处页操作同步点，该检查点无法到达。

### 3.3 ⚠️ 320s 冻结观测 — **存疑（证据缺口），须 CB 补证**

CB 构建史 §14 自述实验：`v1c2_resume.bat` no-cuda-graph 引擎 + `test_stream_stall.py` 停读 320s；t+40s 正常 decode → t+80s CPU 冻结 51.5s → t+320-400s 仍冻结；t+200s TCP 已断仍冻结。

**复核实测（本机，13:10-13:13）**：
- 当前引擎 PID 16596（v1c2_resume.bat，no-cuda-graph）**可正常响应**新请求：req#2 于 13:12:22 完成，TTFT 268ms / total 268ms / output 1（HTTP 200, 472ms 含 RTT）。
- 引擎 CPU 三采样 51.52/51.53/51.53（12 秒内几乎不变）→ **空闲**（非冻结，冻结应完全不变且不响应）。
